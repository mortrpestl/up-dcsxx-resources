2. Celsius ↔ Fahrenheit Converter

- Two input fields side by side — one for °C, one for °F
- Typing in either field instantly updates the other (bidirectional, real-time)
- Conversion formulas: °F = °C × 9/5 + 32 and °C = (°F − 32) × 5/9
- Handle edge cases: empty input clears both fields, non-numeric input is rejected
- Clean, minimal UI with clear unit labels and a reset button
